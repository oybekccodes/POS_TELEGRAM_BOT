# Telegram Bot

Bu Telegram bot mahsulotlarni boshqarish va sotuvlarni kuzatish uchun ishlab chiqilgan. Bot Python 3.12 va `pyTelegramBotAPI` kutubxonasi yordamida ishlaydi.  

## 🔹 Bot funksiyalari

| Buyruq | Tavsif |
|--------|--------|
| 🚀 `/start` | Botni ishga tushirish va boshlash |
| 📷 `/scan` | Mahsulotni skanerlash |
| 🔎 `/search` | Mahsulotni qidirish |
| ➕ `/add` | Yangi mahsulot qo‘shish |
| 💰 `/today` | Bugungi sotuvlarni ko‘rish |
| 📊 `/report` | Oylik sotuvlar hisobotini ko‘rish |
| 📦 `/products` | Sotilgan mahsulotlar ro‘yxati |
| ❌ `/cancel` | Hozirgi amalni bekor qilish |
| ℹ️ `/storage` | Mahsulotlar ro‘yxati |
| ❌ `/delete` | Mahsulotni o‘chirish |

---

## 🔹 Talablar

- Python 3.12+
- `pyTelegramBotAPI>=4.12.0`
- `requests>=2.31.0` (agar bot tashqi API bilan ishlasa)
